Open dist/index.html in a browser or serve dist with any static web host. No build is needed. Google Fonts requires an internet connection.

No ceremony time was supplied. The countdown targets the beginning of 23 December in India, and Add to Calendar creates an all-day event. Get Directions opens a Google Maps search for Bianco Castle, Tirur.

The visual design follows the user-provided reference: https://hisham-suhana.github.io/wedding-invitation/. Artwork has been personalized with built-in Imagegen.
